# URDF 校准自动采样方案

## 首选路线

使用厂家关节位置接口自动摆位，在现场主机上等待停稳并采集实际关节角和对应的末端位姿。AI 负责生成采样计划和离线分析，现场操作员批准运动计划并保有独立的停止手段。设备有示教器时，可把人工点动作为补采入口。

每个机型需要提供关节位置指令、实际关节角反馈、TCP 或法兰位姿，以及控制器状态、限位和已验证的停止能力。采样动作使用控制器的原生关节坐标，URDF 和 Pink IK 用于离线对账。控制器内置 FK 的读数用于验证 URDF 与控制器的一致性。物理空间的绝对精度需要独立测量。

## T33 离线实现

- 复用 `tools/dm-exo/urdf_fk_calib/urdf_axis_probe.py`。默认只预演，不建立控制器连接。上机入口必须显式选择并绑定操作员批准的计划。
- 分开保存目标和实际反馈。验证关节数、左右臂索引、单位、TCP 顺序和四元数，检查设备状态、故障、响应新鲜度和软限位。采用厂家已确认的动作完成与停止机制。
- 每点确认实际到位并稳定后采样。顺序读取接口可用“实际关节角 → TCP → 实际关节角”交叉检查，前后角度必须在容差内。优先用设备时间戳或序号确认反馈，缺少时记录请求与接收时间和反馈来源。接收时间仅说明应答到达，不能代替设备采样时间。
- 用模拟控制器覆盖正常五点流程、左右 TCP 分包、非法值、故障、过期反馈、断连和回位失败。中止后停止派发新动作，保存已采数据和中止原因。

## T34 第一阶段 · 左臂单关节试采

### 开始前

- 操作员选定单个关节、基准姿态、正反向幅度、速度、回位容差和停稳标准。核对当前故障、限位、安全余量、整段运动的扫掠空间和现场停止手段。
- 确认控制器端的操作模式和控制权。现场人员安排与遥操 Bridge 的切换，核对只有一个运动控制源。现场防护和停止功能独立于远程连接。
- 记录当次基座、工具/TCP、左右臂索引、配置快照和反馈来源。先静止读数，确认反馈可用。

### 采样顺序

| 点位 | 预期动作 | 记录重点 |
|---|---|---|
| 1 | 当前基准 | 初始实际关节角和 TCP |
| 2 | 目标轴正向 | 正向实际变化及末端位姿 |
| 3 | 回基准 | 首次回位误差 |
| 4 | 目标轴反向 | 反向实际变化及末端位姿 |
| 5 | 回基准 | 第二次回位误差 |

每点保存运行与点位标识、控制目标、实际关节角、原始 TCP 位置和姿态、时间戳、控制器状态和停稳判定。保留原始响应与规范化结果。敏感现场原始数据按现场约定保存，公开任务中记录脱敏摘要和受控证据引用。

### 通过与中止

- 五个点均可复核，三个不同姿态清楚可分。目标轴的实际反馈有可区分的正反向变化，其余轴在约定容差内，两次回位均有实际反馈证据。
- 用已核对的坐标约定对比实际 TCP 相对运动与 URDF 预测。信号不足时记录 `UNCERTAIN`，补测动作由现场重新确认。单轴通过只验收采样链路，T34 仍需逐轴验收。
- 发现断连、反馈过期、控制权冲突、控制器报错、异常运动或回位失败，按现场已验证的停止流程中止并由操作员接管。异常退出路径只保留已有记录和中止原因，后续恢复动作由操作员决定。

## 后续采样

左臂七轴验证通过后，再采肩、肘、腕的不同组合，覆盖常用遥操区域。清理重复构型和异常反馈，把拟合与独立验收数据分开。离线先检查关节坐标和基座/TCP 定义，再决定是否拟合几何参数。报告修正前后的 TCP 位置、姿态和运动方向误差。
