## 阻断项

1. `sweep_calib.py:190` 左右，默认路径在判断 `--go` 前就构造 `Ctrl()`、连接控制器并读取状态；dry-run 不满足离线不连接要求。
2. `sweep_calib.py:114-128` 内层用 `q17 = frame` 覆盖实际反馈，下一次循环以本地指令判断到位，冻结反馈也可报告成功。
3. `dev_state()` 只取 state，忽略 hardwareErrors/softwareErrors/motorErrorDetails/协议错误；drive 内没有逐步完整状态检查，且拒绝后减步继续派发。故障后仍可能发送 stop_motion，缺少 T33 的 fail-closed 策略。
4. 位姿清单使用历史静态 LIMITS；执行时未读取当次 get_config、未严格校验 17 维反馈、有限值、占位槽与 TCP 四元数。九点禁区采样及插入路点没有证明整段路径安全。
5. socket 与记录文件未统一由 try/finally 管理；异常路径不能保证保留中止原因和可靠关闭资源。
6. 旧方案把 DH 路线称为 T39、允许直接 60 位姿/臂，与现行 T39（#21/#22 CSV 离线候选）、T34 单轴五点批准入口冲突；拟合验收 max 100mm 与新门禁 max 20mm 也需区分研究判据和生产验收。

## 两个完全离线复现

从上述 head 用 git show 读入 sweep_calib.py，exec 为隔离模块。socket.create_connection 被 mock 为抛出 AssertionError；运动 send/pump/q 全部 mock，没有打开 socket、没有控制器连接或运动命令。

- 默认入口：给仅含一个零位姿的临时 JSON，argv 不带 --go。mock create_connection 被调用 1 次，报 `MOCK: attempted controller connection`。
- 虚假到位：构造 Ctrl（绕过 __init__），q() 恒返回 17 个 0，step=0.005，目标左 J1=0.01，其余为零。drive 返回 `reached=True`、reported_J1=0.005，而 actual_J1=0.0，实际目标误差 0.01 > 到位阈值 0.008。send 只写内存列表（1 帧）。
