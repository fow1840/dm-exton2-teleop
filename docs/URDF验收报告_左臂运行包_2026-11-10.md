## 2. 为什么运行包不能验 URDF（实测证据）

`/target_robot/left_ee/state` 有两个发布者：`ik_node`（指令 FK，`publish_commanded_ee_state`）与
`robot_fk_adapter`（由 TF 算的反馈 FK）。两者都用同一份 URDF，且包里没有控制器实测 TCP。

用 `tools/dm-exo/urdf_fk_calib/verify_bags_urdf.py` 逐包判定 state 每条消息的来源
（对 `FK(q_ik)` / `FK(q_rob)` 的最小残差，位置<1mm 且姿态<5° 才算匹配）：

| 指标 | 数值 |
|---|---|
| 包数 | 56 |
| state 消息总计 | 143 976 |
| **判定为 ik 指令 FK** | 107 541（**74.69%**），残差 **0.000mm / 0.00°** |
| 判定为 rob 反馈 FK | 968（0.67%，且这些样本残差同样 ~0.000mm，因两侧同一 URDF） |
| 两者皆可（静止期 ik≡rob，不可分） | 35 467（24.63%） |
| ik 占比 = 100% 的包 | 18 个 |

典型样例（`press03_left_142721.npz`）：vs `FK(q_ik)` 位置 median **0.000mm** / 姿态 **0.00°**；
vs `FK(q_rob)` 位置 median 6.818mm / 姿态 0.86°（= 真机跟踪误差，不是 URDF 误差）。

判决：`state` 通道是 URDF 的自投影，残差 0.000mm 只证「链路自洽」，**不证「模型=真机」**。
另：`dir01_left.npz` 的 `/rob_v` 与 `/ik_v` 左臂逐点相等（指令回声，WORKLOG 2026-11-06 17:2x 已记），
该包反馈列不可用于对账。

- 合计 **max 1757.5mm（raw）/ 1894.6mm（+0.145m 工具假设）、姿态 max 167.0°**，与 T20 台账
  记录的「292~1895mm / 100~167°」一致，复算通过。
- 独立位姿只有 **7 个**（< G3 门限 20 组，甚至 < 粗判 6 组余量很小）。去重证据：
  `calib_samples_L_1106_0943` 后 4 行与首行 q 差 ≤1e-4 rad、TCP 差 ≤1e-4 m。
- 前序已做过且失败的可救性尝试（不重复跑，见 WORKLOG 2026-11-06 17:2x）：符号枚举 ±1^7
  → 488mm 不可救；置换×符号 5040×128 → 336mm/105°；置换×符号+零偏 LM → 554mm；
  基座(6)+工具(1)+四元数约定×符号联合拟合 → 姿态 37.9°~49.8° 无一塌缩。

判决（沿用 T20，未翻案）：**结构性不一致，符号层/基座拟合都救不回；样本量也不足 G3 门限。**

## 4. G0/G1/G2 桌面三门（本次新跑）

工具：`python3 tools/dm-exo/urdf_fk_calib/offline_gates.py <urdf> --config-json … --bridge …`

- **G0 限位三方**：URDF vs `get_config` 快照，双臂 14 轴**全轴一致**，差值恒为内缩 0.02rad
  （例：Joint2L URDF `[-2.3362,+0.2400]` vs cfg `[-2.3562,+0.2600]`）。0/0 占位限位 0 个。
  可动关节 14（R1-7 + L1-7），关节数 = 协议 14 臂维对上。
  ⚠️ `get_config` 现场返回是 **14 维无腰/头**（前 7 与后 7 同值），与协议 17 维下标不同，解析时别错位。
- **G1 结构**：全 14 轴 `axis=[0,0,1]`（无非 z 轴）；左右臂 origin **非简单镜像**（Joint1R z=-0.194/Rz=-π
  vs Joint1L z=+0.194/Rz=-π；Joint3/5/7 x 同号、rpy 反号）——属「手工重写的镜像链」，不是 SW 原导出。
  根连杆 `base_link`，固定关节 `base_link_to_base(rpy=(-1.5708,-1.5708,0))`，末端 `Link7` / `Link7L`。
- **G2 自洽**：独立 URDF 语义组合（自己叠 origin×axis）vs pinocchio FK，20 随机位形：
  `Link7L` 位置 max **0.000000mm** / 姿态 max 0.000002°；`Link7` 同。→ 实现自洽，**不代表匹配真机**。
