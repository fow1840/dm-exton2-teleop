## 二、诊断方法论（跨项目可复用，已入用户级规则）

1. **快速实验五问**（假设/改什么/预期/判据/回退）——现场唯一工作方式（`docs/机器人现场调试手册.md`）
2. **消极证据≠证据**：无离合时 `sent=0` → `reject=0` 是假象；判据必须验证"该发生的事件发生了"
3. **判据先校准再用**：健康态+故障态各观测一次确认指标区分力，否则标「未验证」
4. **静默失败用离线回放量化**：日志会低估（实例：日志 7 次 vs 回放 13% 帧拒解）
5. **上游无罪定责法**：相关链逐段归责（exo→target corr=1.000 → 断点锁定下游）
6. **逐维度核对**：位置≠姿态、单步≠连续、活跃期≠空闲期、正常路径≠恢复路径
7. **影子模式先行**：只算不发拿同窗基线，硬数据决定放行切换
8. **进程纪律**：杀进程按 PID；同命令字面串自匹配=杀自己 shell（exit 255 两次实踩）；
   `pkill -9` 打 ros2 launch 会孤儿化 robot_state_publisher → 幽灵 TF（差轴置换+1.24m）
9. **门禁防管道掩盖**：timeout/head 链加 pipefail；冷启动工具（topic hz 首条 4s）不能当门禁
10. **算力判据不用 CPU%**：容器内看 load/idle 背离 + vmstat r + /proc/loadavg 旁证
11. **无损改动=门控+逐位 diff**：新行为参数门控默认关，关态与改前逐位一致才算零变化
12. **静态资料先核对再用**：档案限位表过时 1.22rad 实例（T23 当场抓获）
13. **fetch-first**：接手先 fetch 重读远端台账，防过期地图/撞号（workflow-fetch-first，PR #15）
14. **启动成功≠链路可用**：四证据判据（connected+同步/30485 唯一 ESTAB/cmd_rx 增长/无离合基线）

## 三、方向/标定领域知识（本项目核心难题域）

1. **三坐标系模型**：外骨骼 vendor 黑盒系 / URDF CAD 系 / 控制器固件 D-H 系从未对账（`docs/方向诊断与校准系统.md` §一）
2. **方向乱三层分解**：①关节方向层（翻转表/自动采样探针）②末端映射层（sixdir）③运动学结构层（厂商 D-H 或数值重建）
3. **sixdir 六方向标定**（~15min/臂）：录 6 段→segment 识别→measured 回收当前方向表→desired 拟合→verify <3mm 泄漏门限
4. **ArmPoseMap 数学**：3×3 正交映射+缩放+伪向量 det 符号规则（镜像阵换基补负号，否则悄悄翻轴）+正交 Procrustes 拟合+validate 硬门禁
5. **D-H 参数**：固件真账本（4 参数/关节+零位+正方向）；向厂商索取五项清单见 TASKS T24；验收门=6 样本 FK 对账 <20mm/2°
6. **数值重建路线**（T20/T39）：(q, get_tcp_pose) 采样→DH 家族匹配；采样分档 6 组粗判/20 组验收/60 组重建（`docs/URDF真机验收方案.md` 五道门 G0-G4）
7. **降敏双层**：映射层 position_scale 0.30 / orientation_scale 0.20 + 下发层 max_joint_step_rad 0.20→0.02；不靠降频率降敏
8. **遥操语义**：T5 是末端增量遥操（离合锚定+相对增量），不是外骨骼关节直映射——查方向问题先分清改哪层

## 五、流程与协作纪律

1. 台账四件套 + **总览速查表** + 卡点标签强制（`[待部署]/[待真机]/[待验收]/[待硬件]/[待现场]`；DONE=全部验收项有证据）
2. 多 AI 协作流：Issues 认领（[CLAIM]→Assignee→标签）→ 分支 PR（不直推 main）→ CI → 合并（T31~T38 实例）
3. 部署纪律：推前备份+md5 对比、diff 确认只含本实验改动、当天入仓、有副本的配置必须同源
4. 真机窗口稀缺：离线备好一切（代码/回归/判据/采样方案），现场只做部署、验证、录包
5. 解释器并行边界：GIL 串行化重计算（threads 101Hz vs procs 254Hz 实测）；原生扩展多版本共存会段错误（pin 2.7+4.0）

## 六、硬件红线（DM-EXton2 专属，驱臂前必读）

1. `auto_enable:=false` 是安全门禁不可改；`move_speed` 不动

3. J7 停在限位附近，离核实机手勿扶关节；首次自动动作逐段小步人在旁
4. 堵转史：电机7（左，两次复发）/电机14（右腕，档案载反复堵转）；检修前禁遥操
5. 控制器访问：SSH .60 root/wanghuo；5566 Web UI 密码 123456（HANDOFF §零）
6. canfd 队列自愈、-100 占位轴可解析（T09 协议层三步已验）；movej 不可遥操（程序重叠拒）
