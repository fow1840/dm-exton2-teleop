# 天创真机联调 · 完整命令清单（PC-A 一机跑全）

前提：PC-A = Ubuntu 22.04 + Humble；外骨骼 `192.168.61.15`；wanghuo `192.168.61.60:30485`  
原则：**每条常驻程序各开一个终端，保持不关**；查 topic 另开监控终端。

---

## 0. 一次性准备（做完可跳）

```bash
# 网络
ping -c 3 192.168.61.15
ping -c 3 192.168.61.60
# 关闭占用 30485 的机械臂图形界面！

# ROS 环境写入 bashrc（若未写过）
echo 'source /opt/ros/humble/setup.bash' >> ~/.bashrc
echo 'export ROS_DOMAIN_ID=42' >> ~/.bashrc
echo 'export ROS_LOCALHOST_ONLY=0' >> ~/.bashrc
source ~/.bashrc

# yaml 已改为 192.168.61.15（MessageBridge + Puppetry），base_frame=base_link

# 编译 demo（仅首次）
cd ~/exton_ros2_retargeting_demo
python3 -m venv pink && source pink/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
source /opt/ros/humble/setup.bash
colcon build --symlink-install
mkdir -p ~/tcvg && cp scripts/exton_bridge.py ~/tcvg/
chmod +x ~/Install/install_ros2/bin/ROS_2/MessageBridge
chmod +x ~/Install/install_ros2/bin/Puppetry/Puppetry
```

## 1. 真机联调（严格按顺序 · 共 5～6 个终端）

### ① 外骨骼
长按开机 → 等自检完成 → PC-A：`ping -c 3 192.168.61.15`

---

### ② 新开 T1 — MessageBridge（保持）

```bash
export ROS_DOMAIN_ID=42
source /opt/ros/humble/setup.bash
cd ~/Install/install_ros2/bin/ROS_2
./MessageBridge
```

成功：出现 `message_bridge` started

---

### ③ 新开 T2 — FK 真机（保持）

```bash
export ROS_DOMAIN_ID=42
source /opt/ros/humble/setup.bash
source ~/exton_ros2_retargeting_demo/install/setup.bash
ros2 launch robot_fk_adapter robot_fk_adapter.launch.py \
  use_sim:=false use_rviz:=true
```

注意：`use_sim:=false` 必须

---

### ④ 新开 T3 — bridge（保持）

```bash
export ROS_DOMAIN_ID=42
source /opt/ros/humble/setup.bash
source ~/exton_ros2_retargeting_demo/install/setup.bash
python3 ~/tcvg/exton_bridge.py --ros-args \
  -p control_mode:=movej \
  -p move_speed:=15.0 \
  -p auto_enable:=false
```

成功：已连接 `192.168.61.60:30485`

---

### ⑤ 新开 T4 — Puppetry（保持）

```bash
export ROS_DOMAIN_ID=42
source /opt/ros/humble/setup.bash
cd ~/Install/install_ros2/bin/Puppetry
./Puppetry
```

成功：`Puppetry initialized`

---

### ⑥ 新开 T5 — IK（保持）

```bash
export ROS_DOMAIN_ID=42
source /opt/ros/humble/setup.bash
source ~/exton_ros2_retargeting_demo/pink/bin/activate
source ~/exton_ros2_retargeting_demo/install/setup.bash
ros2 launch robot_ik_retargeting ik_retargeting.launch.py
```

（若用客户自研 IK，跳过本步，改为启动客户节点）

---

### ⑦ 可选 · 新开 T6 — 监控（可关）

```bash
export ROS_DOMAIN_ID=42
source /opt/ros/humble/setup.bash
source ~/exton_ros2_retargeting_demo/install/setup.bash

ros2 topic hz /client_robot/joint_states
ros2 topic hz /target_robot/left_ee/state
ros2 topic echo /clutch/left
ros2 topic echo /target_robot/joint_commands --once
```

## 2. 试控

1. 穿好外骨骼，姿态大致对齐机器人  
2. **不按 Clutch** → 真机应不动  
3. **按住**左/右 Clutch → **极慢、小范围**动手臂 → 看真机/RViz  
4. **松开 Clutch** → 应停止  
5. 换另一侧再测

## 3. 一页对照

| 终端 | 命令摘要 | 关不关 |
|------|----------|--------|
| T1 | `./MessageBridge` | 保持 |
| T2 | FK `use_sim:=false` | 保持 |
| T3 | `exton_bridge.py` | 保持 |
| T4 | `./Puppetry` | 保持 |
